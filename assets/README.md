# Application assets

Coloca aquí únicamente recursos que la aplicación utiliza directamente.

Ejemplos:
- `images/`: imágenes propias o con licencia compatible.
- `fonts/`: fuentes autorizadas para redistribución.
- `audio/demo/`: clips de audio propios, libres de derechos o autorizados.

Evita subir canciones comerciales completas. Para probar localmente, puedes seleccionar archivos desde tu dispositivo sin incorporarlos al repositorio.
