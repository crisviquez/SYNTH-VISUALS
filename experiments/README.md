# Experiments

Prototipos pequeños que prueban una sola idea. Cada experimento debe tener una pregunta y un resultado esperado.

Ejemplos:
- `01-basic-shapes/`: formas y coordenadas.
- `02-radial-lines/`: ángulos, seno y coseno.
- `03-particles/`: movimiento y ruido.
- `04-audio-waveform/`: representación de la forma de onda.
- `05-audio-spectrum/`: espectro de frecuencias.

Puedes usar el p5.js Web Editor al principio y guardar aquí el código o los enlaces cuando el experimento sea útil.
