# Decisiones técnicas

Registra aquí las decisiones importantes. No documentes cada detalle trivial.

## Plantilla
### YYYY-MM-DD — Título
- **Contexto:** ¿qué problema o decisión existe?
- **Opciones:** ¿qué alternativas se consideraron?
- **Decisión:** ¿qué se eligió?

## Decisiones iniciales

- JavaScript, HTML y CSS.
- p5.js para dibujo y animación.

Esta decisión puede cambiar si un experimento revela una limitación concreta.
