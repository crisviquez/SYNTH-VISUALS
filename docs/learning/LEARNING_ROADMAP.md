# Learning Roadmap

## Orden general
1. JavaScript esencial.
2. HTML y CSS básicos para interfaz.
3. p5.js: dibujo y animación.
4. Matemáticas visuales: coordenadas, ángulos, seno/coseno, ruido.
5. Fundamentos de audio digital.
6. p5.sound y análisis de audio.
7. Visualizadores reactivos y suavizado.
8. Arquitectura de la aplicación.
9. Captura y grabación de audio/video.
10. Pruebas, rendimiento, GitHub y publicación.

## Regla de aprendizaje
Para cada concepto: entenderlo, practicarlo en un experimento pequeño, explicarlo con tus palabras, integrarlo al proyecto y documentar qué aprendiste.

## Registro de progreso
Marca un tema como aprendido solo cuando puedas hacer una pequeña prueba sin copiar todo de un tutorial y explicar por qué funciona.
