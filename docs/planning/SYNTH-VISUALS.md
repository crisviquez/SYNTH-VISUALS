# SYNTH-VISUALS

## 1. Descripción

SYNTH-VISUALS es un proyecto de programación creativa que busca transformar canciones en experiencias audiovisuales generativas. Mediante una aplicación web, el usuario podrá reproducir música, seleccionar estilos visuales, personalizar sus características y exportar las animaciones como videos.

El proyecto combina programación, análisis de audio y diseño visual, con el objetivo de aprender nuevas habilidades y crear piezas audiovisuales originales.

## 2. Objetivos

### Objetivo general

Desarrollar una herramienta web que permita generar visualizaciones musicales personalizables y convertirlas en piezas audiovisuales que puedan compartirse.

### Objetivos específicos

- Aprender los fundamentos de JavaScript y la programación creativa con p5.js.
- Comprender cómo analizar audio y utilizar sus características para controlar animaciones con three.js y otras bibliotecas.
- Experimentar con diferentes estilos visuales, composiciones, colores y movimientos.
- Crear una interfaz sencilla para personalizar las visualizaciones.
- Implementar una forma de grabar y exportar los resultados como video.
- Documentar el proceso de desarrollo mediante GitHub y videos cortos.

## 3. Público objetivo

El proyecto está dirigido inicialmente a su propio desarrollador como herramienta de aprendizaje y experimentación artística. En el futuro, podría adaptarse para artistas musicales, creadores de contenido y personas interesadas en generar visuales para canciones.

## 4. Alcance de la primera versión

La primera versión deberá permitir:

1. Cargar y reproducir una canción compatible.
2. Analizar el sonido para obtener información útil para la animación.
3. Visualizar la música mediante al menos dos estilos gráficos diferentes.
4. Modificar parámetros visuales, como colores, velocidad, tamaño y sensibilidad al audio.
5. Grabar y exportar una visualización como video, con las limitaciones técnicas del navegador documentadas.

## 5. Dirección artística

El proyecto no tendrá una única estética definitiva durante su etapa inicial. Se experimentará con estilos abstractos, geométricos, minimalistas, tipográficos, de partículas y de alto contraste.

Se prestará especial atención a la relación entre sonido, movimiento, composición y ritmo. Las referencias visuales se recopilarán antes de definir una identidad gráfica más consistente.

## 6. Tecnologías previstas

- **HTML y CSS:** para la estructura y la interfaz.
- **JavaScript:** como lenguaje principal.
- **p5.js:** para la generación de gráficos y animaciones.
- **p5.sound y las herramientas de análisis de audio del navegador:** para explorar la relación entre música y visuales.
- **Three.js:** para generación de gráficos en 3D.
- **Git y GitHub:** para el control de versiones y la documentación.
- **GitHub Pages u otra alternativa compatible:** para publicar una demostración web.

Las tecnologías y los métodos de exportación podrán ajustarse según las necesidades que aparezcan durante el desarrollo.

## 7. Fuera del alcance inicial

La primera versión no incluirá cuentas de usuario, almacenamiento en la nube, integración con servicios de streaming, detección automática de géneros, edición multipista ni un editor audiovisual completo.

Estas funciones podrán evaluarse después de comprobar que el concepto principal funciona.

## 8. Metodología de trabajo

El proyecto se desarrollará de forma incremental. Cada etapa tendrá un objetivo concreto y un resultado verificable. El aprendizaje teórico se combinará con pequeños experimentos y su aplicación directa al visualizador.

Se utilizará GitHub para organizar el código, registrar avances y documentar decisiones. También se crearán videos cortos que muestren tanto el proceso de aprendizaje como los resultados visuales.

## 9. Criterios de éxito

La primera versión se considerará satisfactoria cuando sea posible cargar una canción, visualizar su comportamiento mediante distintos estilos, modificar los parámetros principales y generar un video reproducible.

Además, el proyecto deberá estar documentado y contar con una demostración visual que permita entender su propósito.

## 10. Posibles ampliaciones

Entre las mejoras futuras se encuentran nuevos estilos visuales, presets personalizables, tipografía animada, formatos verticales para redes sociales, transiciones y herramientas orientadas a la creación de contenido musical.
