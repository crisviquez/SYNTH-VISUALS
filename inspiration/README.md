# Inspiration / Moodboard

Guarda referencias visuales y registra qué te interesa de cada una.

## Cómo documentar una referencia
- **ID:** REF-001
- **Enlace/origen:**
- **Tipo:** visualizador circular / partículas / fondo ambiental / tipografía / otro
- **Qué me gusta:** composición, forma, movimiento, paleta, ritmo...
- **Qué puedo aprender:** técnica o idea general que podría experimentar.
- **Qué no copiar:** elementos de marca, diseños distintivos o recursos sin permiso.
- **Licencia/uso:** referencia privada, licencia conocida o permiso requerido.

## Archivos
- `references.md`: índice de referencias.
- `images/`: capturas pequeñas para uso de referencia personal, respetando derechos de autor.

No asumas que una imagen encontrada en internet puede usarse dentro de la aplicación o en videos publicados. Para assets finales, verifica la licencia o crea recursos propios.
