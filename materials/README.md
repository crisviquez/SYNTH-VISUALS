# Materials

Recursos que podrían reutilizarse en el proyecto, como:
- Paletas de colores creadas por ti.
- Fuentes con licencia compatible.
- Texturas y patrones propios.
- Plantillas de composición.
- Notas de exportación y formatos.

Incluye un `LICENSES.md` para registrar autoría, origen, licencia y atribución. No guardes aquí recursos de procedencia desconocida.
