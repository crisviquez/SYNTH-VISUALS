# Showcase

Guarda una selección pequeña de resultados que muestren la evolución del proyecto.

- `screenshots/`: capturas optimizadas.
- `gifs/`: demostraciones cortas y ligeras.
- `videos/`: solo videos pequeños que tenga sentido versionar.
- `gallery.md`: índice con fecha, versión, descripción y enlaces.

Los renders grandes deben guardarse fuera del repositorio (por ejemplo, almacenamiento externo) y enlazarse desde aquí, para no inflar el historial de Git.
