# Tests

Registra pruebas manuales y automatizadas.

## Pruebas manuales iniciales
- [ ] La página se carga sin errores.
- [ ] El audio compatible se puede seleccionar y reproducir.
- [ ] Cambiar de visualizador no detiene inesperadamente el audio.
- [ ] Los controles actualizan la visualización.
- [ ] El comportamiento es razonable con canciones lentas y rápidas.
- [ ] La grabación incluye audio y video.
- [ ] Se informa al usuario si el formato de exportación no es compatible.

Al principio, una lista de pruebas manuales es suficiente. Añade pruebas automatizadas cuando la lógica tenga tamaño y estabilidad suficientes.
