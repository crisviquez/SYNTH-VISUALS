# Source code

El código de la aplicación vivirá aquí cuando comience la implementación.

Estructura futura posible:
- `main.js`: inicialización y coordinación general.
- `audio/`: carga, reproducción y análisis de audio.
- `visualizers/`: cada estilo visual como módulo independiente.
- `controls/`: controles de la interfaz y parámetros.
- `utils/`: funciones reutilizables.

No crees todos estos archivos hasta que exista código que justifique separarlos.
