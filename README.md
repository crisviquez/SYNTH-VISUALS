# SYNT-VISUALS

Proyecto de programación creativa para transformar canciones en piezas audiovisuales generativas.

## Estado
Fase de planificación. Todavía no hay implementación de la aplicación.

## Objetivos
- Aprender programación creativa con JavaScript y p5.js.
- Analizar audio y utilizarlo para controlar visualizaciones.
- Experimentar con estilos generativos y fondos ambientales.
- Crear una interfaz sencilla para personalizar visuales.
- Exportar resultados como videos y documentar el proceso.

## Primer MVP
- Cargar y reproducir un archivo de audio compatible.
- Mostrar dos estilos visuales iniciales.
- Reaccionar a amplitud y/o bandas de frecuencia.
- Permitir ajustes básicos de color, velocidad e intensidad.
- Investigar y probar la grabación de audio + video en navegador.
